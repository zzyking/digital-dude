
## 主要组件介绍

### App.tsx
主应用组件，负责：
- 整体状态管理
- 媒体流控制
- 多模态数据融合
- 与后端API通信

### DigitalHumanWebRTC.tsx
WebRTC数字人组件，功能：
- 建立WebRTC连接
- 接收数字人视频流
- 管理连接状态

### VisionRecognition.tsx
视觉识别组件，支持：
- 人脸表情识别
- 手势识别
- 实时视频处理

### VoiceRecognition.tsx
语音识别组件，提供：
- 实时语音转文字
- 支持多种语音识别引擎
- 音频可视化

### ChatInterface.tsx
聊天界面组件，包含：
- 消息列表显示
- 文字输入功能
- 消息历史管理

## 技术特点

### 多模态融合
- 将表情、情绪、手势信息融合到对话上下文
- 前端显示纯净的用户输入，后端接收富含上下文的信息
- 支持实时多模态数据处理

### 性能优化
- 使用 React 19 并发特性
- Vite 构建优化
- 组件懒加载
- 缓存机制优化API调用

### 可扩展性
- 模块化组件设计
- TypeScript类型安全
- 灵活的配置系统
- 支持多种AI服务提供商
